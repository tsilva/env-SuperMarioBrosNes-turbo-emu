# supermariobrosnes-turbo migration package

`supermariobrosnes-turbo` has moved to
[`env-supermariobrosnes-turbo-emu`](https://pypi.org/project/env-supermariobrosnes-turbo-emu/).

This final metadata-only release installs the replacement distribution at the
same version. Existing Python imports such as `import supermariobrosnes_turbo`
remain unchanged.
